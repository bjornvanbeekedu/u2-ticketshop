# U2 Ticketshop

## Reflectievragen

1. **Functies:** Je maakt gebruik van functies om het iets te hergebruiken en aanvragen vanaf waar dan ook.
2. **Parameter en return:** Een parameter is iets dat je meegeeft en een return waar iets wat je terug krijgt.
3. **Include:** Include gebruik je om iets er bij in te zetten vanaf een ander bestand.
4. **Voordeel:** Het voordeel is dat het geordend is.
